⚙️ Stack Technique

HTML5
CSS3 + Animations
JavaScript ES6+
Three.js
Google Fonts (Orbitron, Rajdhani)
LocalStorage API
Pas de backend (100% client)

Pourquoi ces choix ?

  • ✅ Three.js : Rendu 3D performant pour les effets spatiaux
  • ✅ Vanilla JS : Pas de framework lourd, rapidité et simplicité
  • ✅ LocalStorage : Sauvegarde offline sans serveur
  • ✅ Architecture modulaire : Facile à étendre et maintenir
  • ✅ Design System : Variables CSS pour cohérence visuelle

🔄 Flux de Données

// 1. AUTHENTIFICATION (index.html) user.login() → validate() → sessionStorage.set('authenticated', true) → trigger hyperspace animation → redirect to galaxy.html // 2. NAVIGATION GALAXIE (galaxy.html) loadProgress() → fetch from localStorage planetClick() → showModal(planetData) → startRevision() → redirect to revision.html?planet=X // 3. RÉVISION (revision.html) loadQuestions(planet) → fetch from data.js answerQuestion() → updateProgress() → saveToLocalStorage() → updateUI() completeSession() → calculateScore() → updateGlobalProgress() → redirect to galaxy.html
